# v0.1.1 · corrective sponsored-journey preview

Corrective preview for the Supporter card's visual presentation. Published as a
non-prerelease GitHub release; this flag does **not** imply production maturity
or activate Base V1, payments, payroll, helper services or migration.

## What changed

- The app header displays **Decent Pilgrimages**, with responsive sizing and
  natural word-boundary wrapping instead of orphan trailing characters.
  The host-only adaptation leaves pinned DecentHead vendor source unchanged.
- Browser acceptance at **1440, 390 and 320 px** checks the exact title text,
  character-level integrity of each word and viewport bounds.
- Preparation and announcement callers pin shared DecentHead
  `599241344849af1921f6a9a59431f4b2f300d417`, including the parent's corrected
  generic card-title rendering.
- The receipt-gated About card now expects **v0.1.1** evidence and rejects
  superseded v0.1.0 evidence.
- The legacy GitHub Pages root now redirects into the actual `public/` app,
  preserving query/hash instead of displaying the README. Canonical app URL:
  **https://thejollylama.github.io/DecentPilgrimages/**.
  Browser acceptance follows the real redirect and opens pending About;
  the parent separately checks deployed publication. No Pages settings change.

## v0.1.0 is frozen, unminted and superseded

v0.1.0 preparation succeeded, but front-art review found orphan characters in
the app header and generic card title. Its assets are not replaced or rewritten.
**Do not mint using v0.1.0's preparation/mint issue.** The parent coordinates
explicit supersession of that issue. v0.1.1 is the corrective mint candidate;
successful preparation and public-artifact review are still required.

The geographic trail explorer, optional advisory/memory-only GPS, tutorial,
local journal, shared Head and opt-in radio are unchanged. Base V1 remains
unconfigured; Gate V2 remains an undeployed prototype; video/knowledge services,
payroll and helper remain unavailable/disabled.

(`10000000` raw units), Base **8453**, existing NFT

The About card remains preparing/unavailable without steward-reviewed public
mint/listing evidence. No token ID, listing ID or purchase availability is
fabricated. Future purchase links use the existing external DecentHead checkout.

financial functionality, deployment safety, returns or future delivery.

No financial activation, contract deployment, transaction, ENS change or
historic custody/migration approval is included.
