# v0.1.0 · sponsored-journey preview

A versioned snapshot of DecentPilgrimages' sponsored-journey experience and
development-support preparation. Published as a non-prerelease GitHub release;
**preview** describes its safety-limited scope, not production maturity.

## What ships

- Geographic trail explorer, optional map tiles and advisory, memory-only GPS.
- Six-hop onboarding, accessible About, shared pinned DecentHead, local journal
  export/recovery and opt-in radio.
- Base V1 contracts/ABI and exact-unit organizer/sponsor client, with
  deployment configuration absent and financial writes disabled.
- Local unfunded token-basket design/export/recovery and a separately versioned,
  undeployed Gate V2 prototype. Video/knowledge verification remains unavailable.
- Disabled steward-gated payroll and optional assistant scaffolding.
- About Supporter card that honestly stays **preparing/unavailable** until
  steward-reviewed, verified public mint/listing evidence is configured.
  Any future enabled purchase link uses the existing external DecentHead
  checkout, not a new payment signer.
- Immutable shared Supporter preparation/announcement callers pinned to
  DecentHead `2b87543db1ff5c44c720e5c7f782386bbd702bc1`.
  The runnable exact-tag site is **public/**, with no build step; its project
  attribution and full license texts remain included. The source archive
  preserves the complete tagged repository.

## Supporter edition

Approved configuration: **1,000 editions**, **10 USDC each** (`10000000` raw
six-decimal units), **Base 8453**.

- Existing NFT: `0xe63EC9f8228720bAAC2fD528C0A6d06B3Dc5439B`
- Community escrow: `0x31b07b83e99A9bdF379bf40225b8A80d3804C89d`

These are preparation parameters, **not a mint receipt or listing**. No token ID,
listing ID, purchase availability or successful pin/mint is asserted by these
notes. The user configured `PINATA_JWT`; successful preparation and approved public
manifest/artifact review must precede steward wallet mint/listing.
Announcements remain disabled unless separately configured and authorized.

## Safety and deferrals

Optional support is not a travel reward, contributor payment, proof of health,
financial functionality, deployment safety, returns or future delivery.
Participation remains free.

**No activated Base V1 deployment, live reward funding, payroll payment, helper
service, migration or ENS change is included.** Historical Polygon custody and
migration obligations require separate review. Gate V2 production wiring,
independent deployment/source verification, real-wallet activation acceptance,
video/knowledge services and financial activation are deferred to a separately
authorized version. GPS alone never authorizes payment.

## Validation and open work

Local validation passed:

```sh
npm test
# 35 contract/offline verification tests + 44 UI tests
npm run payroll:validate
# disabled, empty, no payments
npm run test:browser
# 6 Chromium cases, including About at 320/390/1024 px
git diff --check
```

Browser tests use synthetic fixtures and isolated loopback servers, not live
wallet/chain/provider calls. No test result establishes a live mint or payment.

closure. See [the complete release scope, issue/PR/branch dispositions and reuse
